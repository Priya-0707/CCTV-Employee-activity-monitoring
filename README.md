# CCTV-Based Employee Activity Tracking System

## Overview

An ongoing Python-based project designed to track and analyze employee activities using computer vision and video processing.

The system aims to monitor employee activeness, track activity duration, and analyze productivity through an interactive dashboard.

**Current Development:** Webcam input is currently used for video capture, processing, and testing.

**Future Scope:** Integration with CCTV cameras for real-time employee activity monitoring.

## Key Features

- Employee registration and management
- Webcam-based video capture and processing
- Employee activity tracking and analysis
- Activity duration and productivity monitoring
- Interactive dashboard for visualizing employee activities

## Technology Stack

- Python
- Computer Vision
- Video Processing
- Data Analytics
- Dashboard Visualization
